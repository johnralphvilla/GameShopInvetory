# Video Game Shop Inventory System

## About

This is a C# console application that I created for my Object-Oriented Programming course. It is designed to manage the inventory of a video game shop.

The application reads game information from a text file and stores it in an array. Users can add new games, search for games, display the inventory, and view statistical information about game prices.

## Features

- Add new games to the inventory
- Save new games to a text file
- Generate unique four-digit item numbers
- Search for games by item number
- Search for games by maximum price
- Search for games by rating
- Display the complete inventory
- Calculate the average price and price range
- Display the cheapest and most expensive games
- Validate user input

## Game Information

Each game contains:

- Item number
- Game name
- Price
- User rating
- Quantity in stock

## How to Run

1. Download or clone this repository.
2. Open the solution file in Microsoft Visual Studio.
3. Make sure `VideoGames.txt` is included in the project.
4. Build and run the application.

You can also run it from the terminal:

dotnet run
